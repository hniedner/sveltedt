# Departures from DataTables

SvelteDT takes DataTables (datatables.net) as its inspiration and functional template (PRD, section 2, Vision). This
file lists every intentional difference, with its reason, so a project leaving DataTables knows what changes; it also
lists what SvelteDT adds where DataTables has no equivalent. The migration guide (PRD-D8) answers each entry; its docs
test fails on an entry the guide does not have.

Classes: **platform** (Svelte, the browser, the strict content-security policy), **improvement** (shown by a
measurement or a source, not asserted), **best practice**, **standards** (WCAG), **owner** (a scope or product choice
the owner makes). An entry of class owner is the owner's decision; the others are decided under the Vision's rule and
recorded here.
**Status**: decided, or open (an open entry is not built until it is decided).

DEP-34 is withdrawn: `order-column` is matched by PRD-T13 (DEP-31); the number is not reused. DEP-14, DEP-22, DEP-23
and DEP-24 are withdrawn the same way: searching while typing after a pause (PRD-B6), the global search box (PRD-B25)
and the information line (PRD-B26) match DataTables, except where DEP-45 and DEP-49 say; the numbers are not reused.
